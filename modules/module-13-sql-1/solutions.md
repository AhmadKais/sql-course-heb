> רוב המשימות במודול הזה הן על **הצוות שלכם** — אין תשובה אחת. כאן: תשובות למשימה 1, ודוגמאות לשאר.

## ✅ משימה 1 — המפה של SQL

**א.**

| הפקודה | תת‑השפה |
|---------|----------|
| `SELECT` | DQL |
| `TRUNCATE` | **DDL** (לא DML! — מודול 26) |
| `MERGE` | DML |
| `REVOKE` | DCL |
| `SAVEPOINT` | TCL |
| `ALTER` | DDL |
| `UPDATE` | DML |
| `GRANT` | DCL |
| `ROLLBACK` | TCL |
| `CREATE VIEW` | DDL |

> ⚠️ **`TRUNCATE` הוא המלכודת:** הוא מוחק שורות כמו `DELETE` — אבל הוא DDL, ולכן ב‑Oracle עושה `COMMIT` אוטומטי ואי אפשר לבטל אותו.

**ב.**

</div>

```sql
SELECT   s.name AS species, COUNT(*) AS waiting      -- 5
FROM     animal a                                    -- 1
JOIN     species s ON s.species_id = a.species_id    -- 1
WHERE    a.status = 'available'                      -- 2
GROUP BY s.name                                      -- 3
HAVING   COUNT(*) > 1                                -- 4
ORDER BY waiting DESC                                -- 6
LIMIT    3;                                          -- 7
```

```text
species  waiting
-------  -------
Cat      4
Dog      3
```

<div dir="rtl">

**ג.** "ב‑SQL אני כותב **מה** אני רוצה לקבל — 'כל החתולים הזמינים, מהקל לכבד' — ובסיס הנתונים מחליט לבד **איך** למצוא אותם. בשפה רגילה הייתי צריך לכתוב לולאה שעוברת על כל חיה ובודקת."

## ✅ משימה 2 — דוגמה ל"חוזה צוות"

1. **נפגשים** בתחילת כל שיעור ל‑5 דקות (שלוש השאלות), ובימי שלישי ב‑18:00 בזום.
2. **מתקשרים** בקבוצת וואטסאפ של הצוות בלבד — לא בפרטי — כדי שכולם יראו.
3. **מי שלא יעמוד במשימה** — מודיע **עד יום לפני** המועד, ומבקש עזרה. בלי הפתעות.
4. **במחלוקת** — כל צד מציג נימוק בכתב (ביומן ההחלטות), ומוביל התחום מכריע. ממש לא מסכימים — שואלים את המורה.
5. **"גמור"** = רץ בלי שגיאה, נבדק על ידי חבר צוות אחר, ונמצא בתיקייה המשותפת.

## ✅ משימה 4 — התנגשות ב‑Git

**ג.** כששניים משנים את אותה שורה, השני שעושה `pull` מקבל **conflict**. Git מסמן בקובץ את שתי הגרסאות:

</div>

```text
<<<<<<< HEAD
CONSTRAINT chk_price CHECK (price > 0)
=======
CONSTRAINT chk_price CHECK (price >= 0)
>>>>>>> origin/main
```

<div dir="rtl">

**פותרים:** מדברים (!), מחליטים איזו גרסה נכונה (מחיר 0 מותר? — שאלה ללקוח), משאירים שורה אחת, מוחקים את הסימונים, ועושים `add` + `commit`. **ההתנגשות היא לא תקלה — היא Git שאומר "שניכם החלטתם דברים שונים; תחליטו ביחד".**
