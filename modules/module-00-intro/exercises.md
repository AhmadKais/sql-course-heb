# מבוא — תרגילי התארגנות

> **למה יש תרגילים במבוא?**
> כי לפני שלומדים לעצב בסיס נתונים, כדאי פשוט **לפתוח עיניים** ולראות שהם נמצאים בכל מקום סביבכם.
> אין כאן שום דבר טכני. אין מה לדעת מראש. צריך רק לחשוב.
>
> ⏱️ זמן משוער לכל התרגילים: **45–60 דקות**
> 📄 פתרו במחברת או בקובץ. אחר כך השוו ל[פתרונות](solutions.md).
>
> **רמות:** 🟢 קל · 🟡 בינוני · 🔴 מאתגר

---

## 🟢 תרגיל 1 — צוד בסיסי נתונים

עברו על **יום רגיל** שלכם, מהרגע שאתם קמים ועד שאתם הולכים לישון.
מצאו **8 רגעים** שבהם נגעתם בבסיס נתונים בלי לשים לב.

לכל רגע כתבו שלושה דברים:

| הפעולה שעשיתי | איזה מידע נשמר/נשלף? | מה היה קורה בלי בסיס נתונים? |
|---------------|----------------------|------------------------------|
| דוגמה: העברתי כרטיס רב‑קו באוטובוס | מספר הכרטיס, הקו, השעה, היתרה החדשה | הנהג היה צריך לרשום ביד כל נוסע |
| | | |

**רמז:** הטלפון בכיס שלכם מדבר עם עשרות בסיסי נתונים לפני שהספקתם לצחצח שיניים.

---

## 🟢 תרגיל 2 — למה זה נשבר?

חנות שכונתית קטנה מנהלת את הלקוחות שלה בקובץ Excel אחד. כך זה נראה:

<div dir="rtl">

ענו:

**א.** דנה עברה דירה. כמה שורות צריך לעדכן? מה קורה אם שוכחים אחת?

**ב.** מצאו בטבלה **שתי טעויות הקלדה** שכבר קרו. מה הן עלולות לגרום?

**ג.** מחיר הקפה מופיע פעם 32 ופעם 35. איזו שאלה זה מעלה? (יש שתי תשובות אפשריות — שתיהן בעייתיות)

**ד.** לקוח חדש נרשם למועדון אבל עוד לא קנה כלום. איך רושמים אותו בטבלה הזאת?

**ה.** במשפט אחד: מה הבעיה **השורשית** של כל התשובות למעלה?

---

## 🟡 תרגיל 3 — פרקו את הטבלה

קחו את הטבלה מתרגיל 2 ופרקו אותה ל**שלוש** טבלאות נפרדות, כך שכל עובדה תיכתב **פעם אחת בלבד**.

לכל טבלה כתבו:
- שם
- אילו עמודות יש בה
- איזו עמודה מזהה כל שורה באופן ייחודי (מספר סידורי זה בסדר גמור)

**רמז:** שאלו את עצמכם "על מה בעצם מדובר כאן?" — התשובות הן שמות הטבלאות שלכם.

---

## 🟡 תרגיל 4 — ראיון בן 10 דקות

מצאו אדם אמיתי שמנהל משהו: הורה בעבודה, בעל חנות, מאמן קבוצה, מנהל ועד בית, אח בבית חולים.
שאלו אותו **חמש שאלות**:

1. אילו רשימות אתה מנהל? (במחשב, בנייר, בראש)
2. איזה מידע אתה מחפש הכי הרבה פעמים ביום?
3. מה הכי מעצבן אותך במערכת הקיימת?
4. איזו טעות עלתה לך הכי ביוקר?
5. אילו שאלות היית **רוצה** שהמערכת תדע לענות עליהן, ואינה יודעת?

**המסירה:** סיכום של חצי עמוד + רשימה של 5–8 "דברים" שהוא מנהל (לקוחות? הזמנות? משמרות? ציוד?).

> 💡 שמרו את הדף הזה. במודול 2 תגלו שזו בדיוק העבודה של מעצב בסיסי נתונים, ואז נלמד לעשות את זה נכון.

---

## 🟡 תרגיל 5 — מה השאלה שלא נענתה?

לכל אחת מהמערכות הבאות, כתבו **שאלה אחת** שהמערכת בוודאי יודעת לענות עליה, ו**שאלה אחת** שהיא כנראה לא:

| המערכת | שאלה שהיא כן עונה | שאלה שהיא כנראה לא |
|--------|-------------------|--------------------|
| אפליקציית משלוחי אוכל | | |
| מערכת הציונים של בית הספר | | |
| קופת חולים | | |
| נטפליקס | | |

**למה זה חשוב?** כי בסיס נתונים לא נבנה כדי "לשמור מידע". הוא נבנה כדי **לענות על שאלות**. אם לא יודעים מראש מה השאלות — בונים את המבנה הלא נכון.

---

## 🔴 תרגיל 6 — מבחן "לפני"

זהו מבחן שאין בו ציון ואי אפשר להיכשל בו. ענו **מהבטן**, בלי לחפש כלום.
שמרו את התשובות בקובץ בשם `before.md`. בסוף מודול 11 תפתחו אותו ותצחקו.

1. מה ההבדל בין **טבלה** לבין **בסיס נתונים**?
2. למה לא פשוט לשמור הכול בקובץ Excel אחד גדול?
3. מה זה "מפתח ראשי" (Primary Key), לדעתכם?
4. אם לכל תלמיד יש כמה מורים ולכל מורה יש כמה תלמידים — כמה טבלאות צריך?
5. מה קורה למחיר שרשום בהזמנה ישנה כשהמוצר מתייקר?
6. תארו בשתי שורות מה עושה הפקודה `SELECT`.

> אין פתרון "נכון" לתרגיל הזה בקובץ הפתרונות — יש שם רק **הסבר קצר לכל שאלה ובאיזה מודול תקבלו את התשובה המלאה**.

---

## 🔴 תרגיל 7 — תכנית העבודה שלכם

זה התרגיל הכי חשוב בדף, ורוב האנשים מדלגים עליו. אל תדלגו.

בנו לוח זמנים אמיתי:

| שאלה | התשובה שלי |
|------|------------|
| כמה שעות בשבוע אני יכול להקדיש? | |
| באילו ימים ושעות בדיוק? | |
| כמה מודולים בשבוע זה אומר? | |
| מתי אני מתכנן לסיים את חלק א' (מודולים 1–15)? | |
| איפה אני שומר את התרגילים שלי? | |
| מי יבדוק אותי / עם מי אדבר כשאיתקע? | |

**חתמו על זה עם תאריך.** ברצינות. זה מכפיל את הסיכוי שתסיימו.
