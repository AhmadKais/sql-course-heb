## 1. DB Fiddle — בלי להתקין כלום

</div>

**מה זה?** אתר שנותן לכם בסיס נתונים שרץ **בתוך הדפדפן**. אין הורדה, אין הרשמה.

**איך מתחילים (30 שניות):**

1. היכנסו ל‑**[db-fiddle.com](https://www.db-fiddle.com)**
2. למעלה משמאל בחרו את סוג בסיס הנתונים — בחרו **SQLite** (הכי פשוט להתחלה)
3. בחלון השמאלי (`Schema SQL`) כותבים את הפקודות שבונות טבלאות
4. בחלון הימני (`Query SQL`) כותבים את השאילתה
5. לוחצים **Run** ⟵ התוצאה מופיעה למטה

**נסו עכשיו** — העתיקו לחלון השמאלי:

</div>

```sql
CREATE TABLE students (
  id      INTEGER PRIMARY KEY,
  name    TEXT,
  grade   INTEGER
);

INSERT INTO students VALUES (1, 'Dana',  95);
INSERT INTO students VALUES (2, 'Yossi', 78);
INSERT INTO students VALUES (3, 'Maya',  88);
```

<div dir="rtl">

ולחלון הימני:

</div>

```sql
SELECT name, grade
FROM   students
WHERE  grade > 80;
```

<div dir="rtl">

התוצאה שתקבלו:

</div>

```text
name   | grade
-------+-------
Dana   | 95
Maya   | 88
```

<div dir="rtl">

| ✅ יתרונות | ❌ חסרונות |
|-----------|-----------|
| אפס התקנה, עובד גם בטלפון | **לא שומר את העבודה שלכם** בין ביקורים |
| קל לשתף קישור עם מורה או חבר | לא מתאים לפרויקט מתמשך |
| מצוין לבדיקה מהירה | אין ממשק גרפי לעיון בטבלאות |

> 💡 **מתי להשתמש בזה:** כשאתם רוצים לבדוק "רגע, איך בדיוק עובד `JOIN`?" ולקבל תשובה תוך 20 שניות.

**חלופה זהה בערך:** [sqliteonline.com](https://sqliteonline.com) — נוח יותר לעיון בטבלאות.

## 2. SQLite + DB Browser — ההמלצה שלנו

### ⭐ אם אתם מתלבטים, בחרו בזה

</div>

**מה זה SQLite?** בסיס נתונים שכל כולו הוא **קובץ אחד** על המחשב שלכם.
אין שרת, אין סיסמאות, אין הגדרות. מעתיקים את הקובץ ל‑USB — העתקתם את כל בסיס הנתונים.

> 🌍 **עובדה מפתיעה:** SQLite הוא בסיס הנתונים הנפוץ בעולם. הוא נמצא בכל טלפון אנדרואיד, בכל אייפון, בכל דפדפן כרום ובכל מטוס איירבוס. אתם משתמשים בו כרגע, כמה פעמים, בלי לדעת.

**מה זה DB Browser?** תוכנה עם **חלונות וכפתורים** שמאפשרת לראות את הטבלאות ולכתוב שאילתות. בלעדיה תעבדו בשורת פקודה — אפשרי, אבל למה לסבול.

### ההתקנה

</div>

```text
שלב 1 ⟶ היכנסו ל-  https://sqlitebrowser.org/dl/
שלב 2 ⟶ הורידו לפי מערכת ההפעלה:
             Windows  ⟶  "DB Browser for SQLite - Standard installer for 64-bit Windows"
             macOS    ⟶  קובץ .dmg
             Linux    ⟶  sudo apt install sqlitebrowser
שלב 3 ⟶ התקנה רגילה: Next ⟶ Next ⟶ Install ⟶ Finish
שלב 4 ⟶ פתחו את התוכנה
```

<div dir="rtl">

### הפעם הראשונה — 4 לחיצות

| # | מה עושים | מה רואים |
|---|----------|----------|
| 1 | לוחצים **New Database** (חדש) | חלון שמירה |
| 2 | שומרים בשם `shelter.db` בתיקייה שלכם | נפתח חלון "צור טבלה" — לחצו **Cancel** |
| 3 | עוברים ללשונית **Execute SQL** | חלון ריק לכתיבת פקודות |
| 4 | כותבים פקודה ולוחצים **▶** (או `Ctrl+Enter`) | התוצאה מופיעה למטה |

### נסו את זה עכשיו

</div>

```sql
-- יוצרים טבלה
CREATE TABLE animals (
  animal_id   INTEGER PRIMARY KEY,
  name        TEXT    NOT NULL,
  species     TEXT    NOT NULL,
  arrival     DATE
);

-- מכניסים נתונים
INSERT INTO animals VALUES (1, 'Luna',  'Dog', '2026-01-15');
INSERT INTO animals VALUES (2, 'Simba', 'Cat', '2026-02-03');
INSERT INTO animals VALUES (3, 'Rocky', 'Dog', '2026-02-20');

-- שולפים
SELECT * FROM animals WHERE species = 'Dog';
```

<div dir="rtl">

> ⚠️ **חשוב מאוד:** ב‑DB Browser השינויים **לא נשמרים אוטומטית**.
> אחרי כל עבודה לחצו **`Write Changes`** (הכפתור למעלה) או `Ctrl+S`.
> אם תסגרו בלי זה — הכול נעלם. זו הטעות מספר 1 של מתחילים בכלי הזה.

| ✅ יתרונות | ❌ חסרונות |
|-----------|-----------|
| התקנה של 5 דקות, ללא שרת וללא סיסמאות | חסרות פקודות מתקדמות שיש ב‑Oracle |
| הכול נשמר בקובץ אחד — קל לגבות ולהעביר | לא בנוי לעשרות משתמשים במקביל |
| רואים את הטבלאות בעיניים, לוחצים ועורכים | סוגי הנתונים "רופפים" יחסית |
| עובד גם בלי אינטרנט | |

**מה מהקורס עובד כאן?** כמעט הכול — כל השאילתות, ה‑`JOIN`־ים, הצירופים והתת‑שאילתות. מה שלא: פרוצדורות (`PL/SQL`) ופקודות ניהול מתקדמות של מודולים 28–32.

## 3. Oracle APEX — סביבת התכנית הרשמית

</div>

תכנית הלימודים של משרד החינוך כתובה סביב **Oracle**. אם אתם ניגשים לבחינה, כדאי מאוד להכיר את הסביבה הזאת.

**החדשות הטובות:** אין צורך להתקין Oracle על המחשב (זה תהליך כבד של שעות). Oracle נותנים **סביבה חינמית בענן**.

### ההרשמה

</div>

```text
שלב 1 ⟶ גשו ל-  https://apex.oracle.com/en/learn/getting-started/
שלב 2 ⟶ לחצו  "Get Started for Free"  ⟵  Request a Free Workspace
שלב 3 ⟶ מלאו: שם, אימייל אמיתי, ושם ל-Workspace (למשל  sqlcourse2026)
שלב 4 ⟶ בדקו את המייל  ⟵  אשרו  ⟵  קבעו סיסמה
שלב 5 ⟶ התחברו. במסך הראשי בחרו:   SQL Workshop  ⟵  SQL Commands
שלב 6 ⟶ זהו. כותבים SQL בחלון ולוחצים  Run
```

<div dir="rtl">

### מה שונה כאן מ‑SQLite?

| הנושא | SQLite | Oracle |
|-------|--------|--------|
| טקסט | `TEXT` | `VARCHAR2(50)` |
| מספר שלם | `INTEGER` | `NUMBER(6)` |
| תאריך היום | `DATE('now')` | `SYSDATE` |
| חיבור מחרוזות | `\|\|` | `\|\|` (זהה) |
| שורה בלי טבלה | `SELECT 1+1;` | `SELECT 1+1 FROM DUAL;` |
| רגישות לאותיות בשמות | לא | לא (אלא אם בגרשיים) |

> 💡 בקורס נציין במפורש בכל מקום שיש הבדל בין הדיאלקטים. אל תדאגו — 90% מהתחביר זהה.

| ✅ יתרונות | ❌ חסרונות |
|-----------|-----------|
| בדיוק הסביבה של תכנית הלימודים | דורש הרשמה עם אימייל |
| כולל `PL/SQL` — פרוצדורות, טריגרים | הממשק עמוס ומבלבל בהתחלה |
| כלי שרטוט ERD מובנה (Data Modeler) | ה‑Workspace יכול לפוג אם לא נכנסים חודשים |
| חינם לחלוטין | דורש אינטרנט |

> ⚠️ **שימו לב:** Workspace שלא נעשה בו שימוש כמה חודשים עלול להימחק. **גבו את הסקריפטים שלכם** לקובץ `.sql` על המחשב.

## 🆘 תקלות נפוצות

</div>

<details>
<summary><b>DB Browser: עשיתי INSERT, סגרתי, והכול נעלם</b></summary>

<br>

לא לחצתם **`Write Changes`**. ב‑DB Browser כל שינוי יושב ב"המתנה" עד שאתם מאשרים אותו.

**הפתרון:** אחרי כל עבודה — `Ctrl+S` או הכפתור `Write Changes` למעלה.
**למניעה:** אם הכפתור צבעוני ופעיל, יש לכם שינויים לא שמורים.

</details>

<details>
<summary><b>XAMPP: MySQL לא עולה, מופיע "Port 3306 in use"</b></summary>

<br>

תוכנה אחרת כבר תופסת את הפורט (בדרך כלל MySQL שהותקן בעבר, או Skype בגרסאות ישנות).

**הפתרון המהיר:** ב‑XAMPP לחצו `Config` ליד MySQL ⟵ `my.ini` ⟵ שנו `port=3306` ל‑`port=3307`, ושמרו.
**הפתרון הנקי:** ב‑Windows פתחו `services.msc`, מצאו שירות בשם MySQL, ועצרו אותו.

</details>

<details>
<summary><b>Oracle APEX: "ORA-00942: table or view does not exist"</b></summary>

<br>

שלוש סיבות אפשריות, לפי סדר השכיחות:

1. **טעות כתיב** בשם הטבלה — בדקו אות אחר אות
2. הטבלה נוצרה ב‑**Workspace אחר** או תחת משתמש אחר
3. יצרתם את הטבלה בגרשיים כפולים (`CREATE TABLE "Animals"`) — ואז השם **רגיש לאותיות** וצריך לכתוב אותו בגרשיים בכל פנייה

**בדיקה מהירה:** הריצו `SELECT table_name FROM user_tables;` — זו הרשימה של כל הטבלאות שלכם.

</details>

<details>
<summary><b>הטקסט העברי מופיע כג'יבריש / סימני שאלה</b></summary>

<br>

בעיית קידוד תווים.

| הכלי | הפתרון |
|------|--------|
| SQLite | עובד ב‑UTF‑8 כברירת מחדל — בדרך כלל תקין. ודאו שהעורך שומר ב‑UTF‑8 |
| MySQL | צרו את בסיס הנתונים עם `CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci` |
| Oracle | ודאו ש‑`NLS_CHARACTERSET` הוא `AL32UTF8` |

**עצה כללית:** בקורס, כתבו **שמות טבלאות ועמודות באנגלית** ושמרו עברית רק ב**תוכן** הנתונים. זו גם הפרקטיקה המקצועית המקובלת, וגם תחסוך לכם הרבה כאב ראש.

</details>

<details>
<summary><b>"מחקתי טבלה בטעות!"</b></summary>

<br>

`DROP TABLE` הוא מיידי ובלתי הפיך ברוב הכלים. אין "בטל".

**מה עושים עכשיו:** מריצים מחדש את סקריפט ה‑`CREATE` וה‑`INSERT` שלכם.
**מה עושים כדי שזה לא יקרה שוב:**

1. שמרו **תמיד** את פקודות היצירה בקובץ `.sql` נפרד. כך שחזור = הרצה של קובץ
2. ב‑SQLite פשוט העתיקו את קובץ ה‑`.db` מדי פעם לגיבוי
3. לפני `DROP` או `DELETE` — הריצו קודם `SELECT` עם אותו תנאי, וראו מה יימחק

</details>

<details>
<summary><b>איזה כלי הכי טוב לשרטוט ERD?</b></summary>

<br>

| הכלי | עלות | הערה |
|------|------|------|
| **נייר ועיפרון** | חינם | ⭐ באמת הכי טוב לטיוטות. אל תזלזלו |
| **draw.io** | חינם | הכי נוח לדיגיטלי, לא דורש הרשמה |
| **Oracle Data Modeler** | חינם | סימון Barker רשמי, כלול ב‑APEX |
| **dbdiagram.io** | חינם | כותבים טקסט ⟵ מקבלים תרשים. מהיר מאוד |

</details>
