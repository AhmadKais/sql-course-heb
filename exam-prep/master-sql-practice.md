## תזכורת: מבנה הטבלאות בבסיס הנתונים `music.sql`

כל שדה בבסיס הנתונים הוא בעל שם ייחודי!

```text
Pupils (תלמידים):
  PupilId (PK), FirstName, LastName, BirthYear, HomeTown (FK -> Cities.CityCode)

Teachers (מורים):
  TeacherCode (PK), TeacherName, TeachInst (FK -> Instruments.InstCode), HourRate, TeacherPhone

Registrations (רישומים - טבלת קשר M:N):
  RegPupil (FK -> Pupils.PupilId), RegTeacher (FK -> Teachers.TeacherCode), 
  RegYear, PupilLevel (מתחיל/ממשיך/מתקדם), MonthlyFee
  PK מורכב: (RegPupil, RegTeacher)

Cities (ערים):
  CityCode (PK), CityName

Instruments (כלי נגינה):
  InstCode (PK), InstName, InstFamily (מיתר / קלידים / הקשה / נשיפה)

Lockers (לוקרים - קשר 1:1):
  LockerNum (PK), LockerPupil (FK UNIQUE -> Pupils.PupilId), LockerFloor
```

## 🔴 רמה 7: שאילתות שמורות ותת‑שאילתה ב‑FROM

**7.1.** תלמיד שמר את השאילתה הבאה תחת השם **Q1**:
```sql
CREATE VIEW Q1 AS
SELECT RegTeacher, COUNT(*) AS PupilCount
```

### 9.5 שאלת מפתחות וקשרים (נכון / לא נכון)
ענו לגבי כל סעיף אם הוא **נכון** או **לא נכון** ונמקו בקצרה:
1. הקשר בין טבלת Pupils לטבלת Lockers הוא קשר של 1:N (אחד לרבים).
2. בטבלת Registrations יש מפתח ראשי מורכב משני שדות.
3. בטבלת Cities יש מפתח זר המפנה לטבלת Pupils.
4. שדה `TeachInst` בטבלת Teachers הוא מפתח זר המפנה ל‑`Instruments.InstCode`.
